# Assets Directory

Place your personal portfolio assets in this folder:

1. `profile.jpg`
   - Your profile portrait or headshot.
   - If not yet added, the website automatically falls back to an animated initials avatar ("KV") with an icy-blue glowing gradient.

2. `resume.pdf`
   - Your official PDF resume file.
   - If not yet added, clicking "Download Resume" opens an informative setup dialog rather than a broken 404 download.
